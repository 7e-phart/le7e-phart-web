# Le 7e Phart - Application Mobile

Application Flutter pour l'association de cinéma Le 7e Phart de Dunkerque.

## Fonctionnalités

- 🏠 Accueil avec actualités et événements
- 🎬 Nos émissions et épisodes
- 🎥 Nos films et documentaires
- 👥 Présentation de l'association
- 📝 Inscription et adhésion
- ✉️ Contact et réseaux sociaux
- 🔐 Espace membre
- 🏢 Espace bureau avec gestion complète

## Installation

1. Assurez-vous d'avoir Flutter installé
2. Clonez ce projet
3. Exécutez `flutter pub get`
4. Lancez l'app avec `flutter run`

## Développement

Cette application utilise:
- Flutter 3.0+
- BLoC pour la gestion d'état
- SharedPreferences pour le stockage local
